# R2 – checklist autora

Checklist je záměrně ponechaný autorovi. Agent jej nezaškrtává za autora.

- [ ] Rozumím expected-hash a workspace revision ochraně zápisu.
- [ ] Umím vysvětlit, co se stane při crashi mezi prepare, publish a confirm.
- [ ] Ověřil jsem diff a bezpečný revert v Git režimu.
- [ ] Ověřil jsem diff a bezpečný revert v non-Git režimu.
- [ ] Zkontroloval jsem dirty Git baseline a zachování indexu.
- [ ] Rozumím jednorázovému approval digestu, claimu a replay ochraně.
- [ ] Zkontroloval jsem stale verification po externí změně workspace.
- [ ] Viděl jsem výsledek timeoutu/cancelu a procesu celého stromu.
- [ ] Rozumím, že Job Object ukončuje podporovaný strom, ale není sandbox.
- [ ] Prošel jsem offline provider kontrakt a ochranu `.codrynignore`/secretů.
- [ ] Rozhodnutí o prvním provideru opírám o datovaný eval, ne o název modelu.
- [ ] Umím zopakovat lokální verify gate a znám jeho neověřené kroky.
