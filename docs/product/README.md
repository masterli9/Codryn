# Produktové podklady

Tato složka obsahuje doprovodné dokumenty aktuálního PRD v1.0, historické
verze PRD, roadmapy, etapizace, registry rozhodnutí a průzkumné návrhy.

Aktuální autority zůstávají v rootu repozitáře:

- `PRD_v1.0.md` — aktuální produktový rozsah (zůstává v rootu)
- `docs/product/PRD_v0.3.md` — historický produktový rozsah
- `ETAPIZACE_v1.0.md`, `REGISTR_ROZHODNUTI_v1.0.md` a `ROADMAP.md` — aktuální
  doprovodné plánovací dokumenty
- `PROJECT_CONTEXT.md` — živý kontext a pravidla projektu
- `AGENTS.md` — provozní pokyny pro AI agenty

Starší dokumenty jsou užitečné pro dohledání vývoje rozhodnutí, ale samy o
sobě nepřebíjejí aktuální PRD a PROJECT_CONTEXT.
